=========== github.com/nn-advith/smolurl ===========
Package main is the starting point of the smolurl application. Smolurl is a
url shortner application that compresses a long url into a shorturl that is
redirectable. like Tinyurl. The application runs as a http server and uses a non
relational database such as couchbase for data persistance. Additional databases
can be configured.

FUNCTIONS

func main()
    main function is the starting function that performs initialization
    tasks and listens for requests. As part of initialization, global logger
    and database connection are configured. The application module is then
    initialized.

=========== github.com/nn-advith/smolurl/logger ===========
package logger // import "github.com/nn-advith/smolurl/logger"

Package logger handles the global logger and it's related functions.

FUNCTIONS

func InitLogger(enableStd bool, enableFile bool) error
    InitLogger initialises the global logger logger.GlobalLogger with a
    combination of terminal and file logs. The required files/directories are
    created and a new instance of logger.Logger is initialised.


TYPES

type Logger struct {
	filelog     bool
	stdlog      bool
	logfilepath string
	logfile     *os.File
	logger      *log.Logger
}
    A Logger writes logs to stdout and/or configured log files, at varying log
    levels. Wrapped over log.Logger

var GlobalLogger *Logger
    Singular, global instance of type logger.Logger, usable from every module.

func (l *Logger) Close()
    Close closes the logfile that is used for file logging. Must be closed
    manually in cleanup or atleast deferred post initialisation.

func (l *Logger) Error(msg ...any)
    Error logs messages at error log level.

func (l *Logger) Fatal(msg ...any)
    Fatal logs messages at fatal log level and exits.

func (l *Logger) Info(msg ...any)
    Info logs messages at info log level.
